# A + B

Read two integers `a` and `b` (|a|, |b| ≤ 10^18, and |a + b| ≤ 10^18) and print `a + b`.

Limits: 1 s, 64 MB, 1 MB of output. Test 1 is a sample; the rest are hidden.

Every file in `solutions/` is named after the verdict it should get:

| File | Expected |
| --- | --- |
| `ac.c`, `ac.cpp`, `ac.py` | AC |
| `wa.cpp` | WA (fails test 2; tests 3 and 4 are SKIPPED for a submission, run for a verify job) |
| `tle.c`, `tle.py` | TLE |
| `mle.cpp`, `mle.py` | MLE |
| `re.c`, `re.py` | RE |
| `ce.c`, `ce.cpp`, `ce.py` | CE (a Python syntax error is CE too) |
| `ole.py` | OLE |
| `escape.py` | WA: the network, other processes and host files are all out of reach, so it prints its findings instead of the answer |
